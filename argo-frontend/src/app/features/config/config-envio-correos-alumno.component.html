Al generar un certificado (manual, por pago, aula virtual o jornada), se envía el PDF al correo registrado del alumno, si tiene dirección válida.

Al registrar un ingreso de alumno (caja, pagos en línea, etc.), se envía el comprobante en PDF al correo del alumno.

Si desactiva una opción, el certificado o el comprobante se genera igual en ARGO; solo se omite el envío automático por correo.
